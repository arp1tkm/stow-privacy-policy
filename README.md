# STOW Privacy Policy

Privacy policy for **STOW**, a Chrome extension designed to quickly save and revisit content from the web.

## Privacy

STOW is designed with a local-first approach. Saved content is stored locally in the user's browser using Chrome's `chrome.storage.local` API.

STOW does not:

* Sell user data
* Use saved content for advertising
* Track browsing activity with third-party analytics
* Upload saved content to a STOW server
* Share saved content with third parties

STOW only accesses and stores content when the user explicitly chooses to save it.
